SpotiDown.co (Sekarang)

  • Audio asli Spotify 320kbps
  • Tanpa API key
  • Tanpa CAPTCHA manual
  • Sudah terbukti jalan
  • Butuh Chrome installed
  • Butuh desktop
  • Nggak bisa di-deploy
  • Tergantung 1 service
  • Free tier: max 100 tracks

YouTube Pipeline (Usulan)

  • Bisa di-deploy ke server
  • Tanpa browser
  • Tanpa CAPTCHA
  • Open source friendly
  • Bisa untuk semua orang
  • Unlimited tracks
  • Audio dari YouTube
  • Kualitas tergantung match
  • Butuh yt-dlp + ffmpeg
  • Kebanyakan butuh API key
  • Belum terbukti jalan

Rekomendasi

  • Prototype dulu: 10 lagu
  • Tes kualitas audio
  • Tes kecepatan download
  • Kalau OK → lanjut bikin lengkap
  • Kalau nggak OK → cari cara lain
